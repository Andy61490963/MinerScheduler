# 獨立離線測試專案

雙擊 `C:\test\PROJECTS\TESTS\執行測試.cmd` 即可執行全部有效測試；唯一流程為 `run_tests.py`。不需要停挖，也不需要管理員權限。

```powershell
& 'C:\test\CORE\TEST_環境\python.exe' -B 'C:\test\PROJECTS\TESTS\run_tests.py'
```

流程先從旁邊的正式原始碼專案建置臨時版本，再執行測試，最後清除臨時檔案。只使用 Python 標準函式庫，不安裝套件。測試以模擬程序、硬體與資料核對網頁監控、開始／停止競爭、設定保存與回復、功耗上限、溫度／感測保護、背景紀錄延遲、初始化冷卻及本地模型協調。

正式運行目錄的寫入及變更、外部程序啟動、顯卡控制函式庫、正式監控／模型與外部連線皆被測試入口拒絕。HTTP 測試只使用臨時本機埠；共享記憶體使用獨立 Local 名稱，不覆寫挖礦心跳。結果保存在本目錄的 `測試結果.json`。

請透過入口執行，避免直接執行個別測試而缺少隔離環境。歷史測試保留在 `C:\test\備份` 的本次整理歸檔，不參與有效測試探索；舊測試包含過往 70%／100% 及升瓦試驗條件，不能當作目前設定。

## 實機短測工具

`tools/功耗短測.py` 是另行執行的實機工具，不屬於 `run_tests.py` 的離線測試，也不會自動執行。只有使用者明確要求測試硬體功耗時才執行，先核對兩組顯卡風扇80%及主機板三組50%，再透過既有一般使用者完整啟動流程挖礦；功耗只能由原有 SYSTEM 保護程式調整。

本次授權為每次30W、每檔5秒，200W開始，最多原廠450W；最後一檔不足30W時只加到450W。保留核心80°C降瓦、82°C停止、感測失效與人工停止優先；本次額外在熱點105°C、顯存90°C或熱降頻時結束加瓦。短測設定有20分鐘期限，逾時回到一般排程，結束亦恢復原設定，不把試驗功耗存為長期設定。實機結果與原設定保存在 `results` 的時間目錄。5秒僅代表瞬時反應，不是長時間穩定性或逐檔算力效率證明。
